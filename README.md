#✨ GenAI Content Hub 

+ A full-stack generative AI platform that leverages the lightweight power of TinyLlama to generate high-quality text content in real-time. 
+ Built with a modern Next.js frontend and a high-performance FastAPI backend.
  
  #🚀 FeaturesReal-time Generation:
+ Streamed or instant text generation using the TinyLlama-1.1B model.
+ Asynchronous Processing: FastAPI-powered backend for efficient request handling.Modern UI: Responsive, sleek interface built with Next.js and Tailwind CSS.
+ Lightweight AI: Optimized for speed and low-latency responses using Hugging Face's transformers.
